# Milestone 02: Air Quality and Asthma Analysis

## Research Question

Is there a relationship between county-level PM2.5 air pollution and adult asthma prevalence in the United States?

This project uses Python to retrieve public data, clean and merge datasets, conduct exploratory analysis, and create visualizations. The goal is not to prove causation, but to examine whether counties with higher measured PM2.5 concentrations also tend to report higher estimated adult asthma prevalence.

---

## Data Sources

### CDC PLACES

The CDC PLACES dataset provides county-level estimates for health outcomes, including current asthma among adults. The notebook retrieves the dataset using the CDC Socrata open data API.

**Source:**
https://data.cdc.gov/resource/swc5-untb.csv?$limit=500000


---

### EPA AirData

The EPA AirData annual concentration file provides monitor-level air quality measurements. The notebook uses the 2023 annual concentration dataset and filters for PM2.5 FRM/FEM Mass using parameter code `88101`.

**Source:**
https://aqs.epa.gov/aqsweb/airdata/annual_conc_by_monitor_2023.zip

## Methods

1. Load county-level asthma estimates from CDC PLACES  
2. Load EPA monitor-level annual PM2.5 data  
3. Clean both datasets and standardize column names  
4. Create 5-digit county FIPS codes  
5. Aggregate EPA monitor-level PM2.5 data to the county level  
6. Merge CDC and EPA datasets using FIPS codes  
7. Calculate descriptive statistics and correlation  
8. Create visualizations to analyze the relationship

## Limitations

This analysis is exploratory and should not be interpreted as causal. Asthma prevalence is influenced by many factors beyond air quality, including:

- Smoking rates  
- Housing quality  
- Occupational exposure  
- Healthcare access  
- Socioeconomic conditions  
- Other environmental pollutants  

Additionally, EPA air quality data is based on monitor locations, which are not present in every county. As a result, the dataset only includes counties with available monitoring data.
